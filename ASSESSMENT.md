# Original self-study assessment

Not an official NUS rubric.

## Can this capstone be used to rank real pupils?

No. The data and task are synthetic, the evaluation is small, and the system lacks the necessary privacy, safeguarding, pedagogical and impact review.

## What is the difference between a demo and evidence?

A demo shows a path can work; evidence includes held-out tests, failed cases, repeatability, provenance and limitations.

## Build task

Produce DATA_CARD.md, MODEL_CARD.md, EVALUATION.md, DEMO.md and an incident runbook. Present one success and two failures, then explain what would change the release decision.

## Suggested scoring, 100 points
- Reproducible clean run and tests: 25
- Correct mechanism and explanation: 25
- Evaluation with a held-out set or explicit mechanism checks: 20
- Failure cases, provenance and limits: 20
- Readable demo and documentation: 10

Pass suggestion: 70, with no fabricated results, private-data exposure or unsupported production claims. This is a self-study convention.
