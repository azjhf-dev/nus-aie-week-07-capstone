# Capstone Project for AI Engineering

## Published scope

Official module link: https://www.comp.nus.edu.sg/executive-education/course/sctp-capstone-project-for-ai-engineering/

Published classroom days: 3. The week below is an original expanded self-study schedule, not the official timetable.

## Learning outcomes
- Frame a problem and measurable acceptance criteria
- Combine a predictor and retrieval helper with source tracing
- Run hold-out tests, inspect subgroup errors and present honest limits

## Five-day learning plan
- Day 1: scope, dataset card and evaluation plan (3h)
- Day 2: baseline pipeline and user interface (4h)
- Day 3: predictor plus retrieval integration (4h)
- Day 4: evaluation, incident drill and fairness caveats (4h)
- Day 5: clean rerun, report and five-minute demo (5h)

## Project
Study-support demonstrator, using only synthetic records and a tiny authored corpus

## Boundaries
Assessment weights, expected capstone size, official datasets and marking rubrics are unpublished in the evidence inspected. The rubric supplied here is an original self-study rubric, not NUS's.

## Completion evidence
- Clean notebook execution and changed-control screenshots
- Exercise code and deterministic tests
- Lab log with at least two failures
- Dataset/model card where appropriate
- Assessment answers before reading the solutions
